## Zen

Zen is an AI-first study companion built with the Next.js App Router. It combines Supabase authentication, Prisma-managed study data, Gemini-powered assistants, OCR ingestion, and a spaced-repetition flashcard flow to help students stay organized and motivated.

### Core capabilities
- **AI Notes & Flashcards** – `/api/ai-notes/generate` calls Gemini 2.5 Flash Lite to summarize pasted text and persist flashcards via Prisma (`src/services/ai-notes.ts`).
- **Goal Helper Chat** – Retrieval-augmented coach that embeds OCR/text uploads into Supabase pgvector and scopes Gemini answers to a student’s notes (`src/app/api/goal-helper/chat/route.ts`, `src/services/vector-store.ts`).
- **Weekly Wrap analytics** – Consolidates sessions, notes, and exams into a motivational report plus “cat personality” generated by Gemini (`src/app/api/weekly-wrapped/route.ts`).
- **Practice exams & study deck** – Study deck, flashcard CRUD, timed sessions, and practice test generation all ride authenticated Supabase sessions and Prisma models under `src/app/api`.
- **OCR + embeddings pipeline** – `/api/extract-text` validates PDF/DOCX uploads, runs OCR.space, and stores the text + embeddings for retrieval (`src/services/ocr-space.ts`).

## Tech stack

| Layer | Details |
| --- | --- |

| Tooling | TypeScript, ESLint 9, Tailwind CSS 4 alpha, React Markdown toolchain |

## Getting started

### Prerequisites
1. Node.js 20+ and npm 10+.
2. Supabase project with tables matching `prisma/schema.prisma` and the `documents` pgvector helper RPC (`match_documents`).
3. API keys: `GEMINI_API_KEY` (and/or `GOOGLE_GENERATIVE_AI_API_KEY`), `OCR_SPACE_API_KEY`.

### Environment variables

| Variable | Description |
| --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | Supabase project URL. |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase anon key for browser + server components. |
| `GEMINI_API_KEY` / `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI Studio key used by LangChain + raw Gemini SDK. |
| `GOAL_HELPER_MODEL` | Optional override for the Goal Helper chat model (defaults to `gemini-2.0-flash-lite`). |
| `OCR_SPACE_API_KEY` | OCR.space key for PDF/DOCX extraction. |

Copy `.env` to `.env.local` and populate the secrets above.

### Install & run

```bash
npm install
npx prisma generate
npm run dev
```

Visit `http://localhost:3000` to access the landing page and `/dashboard` for authenticated routes. Run `npm run lint` before committing to match the shared ESLint config.

## npm scripts

| Script | Purpose |
| --- | --- |
| `npm run dev` | Start the Next.js dev server with hot reload on port 3000. |
| `npm run build` | Produce the production bundle (server actions + RSC). |
| `npm run start` | Serve the contents of `.next` after `npm run build`. |
| `npm run lint` | Run ESLint (`eslint.config.mjs`). |

## Project layout

```
src/
  app/            # App Router entries, API routes, dashboards
  components/     # Reusable UI, grouped by feature (modals, study deck, layout, etc.)
  hooks/          # Custom hooks for timers, forms, etc.
  lib/            # Prisma, Supabase, utility helpers
  providers/      # Client providers (theme, auth, query)
  services/       # Domain services (ai-notes, OCR, vector store)
  types/          # Shared TypeScript contracts
prisma/           # Schema + migrations
public/           # Static assets (hero art, icons, fonts)
docs/             # Architecture overview & API reference
```
